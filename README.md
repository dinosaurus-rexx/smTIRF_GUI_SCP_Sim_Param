# smTIRF_GUI_SCP_Sim_Param
A computer vision workflow for annotating smTIRF events and training the SCP algorithm for case-specific event detection.

Everything lives in the nested `smTIRF_GUI_SCP_Sim_Param/` folder. The real movie and its
labels are **not** in this repo: they are read from the sibling repo
`../BachelorThesis-FRETAlgorithms/realdata/` (`vid_ch1.tiff`, `coord.npy`, `class.npy`).

## Layout

```
smTIRF_GUI_SCP_Sim_Param/
├── GUI2/            Flask annotation tool: TIFF in -> positive/negative event JSONs out
├── SCP/             the detector (LoG blobs + KD-tree tracking) -> detected-events JSON
├── Parameter_opt/   Optuna tuner: runs SCP repeatedly, scores against labels
├── Simulation/      real-calibrated simulator + its validation harness
│   ├── config/        simulator config + targets measured from the real movie
│   ├── tests/         contract tests (axis order, seeding, consumer formats)
│   ├── validation/    gate T1-T5/T7 reports and plots, one folder per simulator
│   └── dataset*/      generated movies (see "Datasets" below)
├── experiments/     one folder per recorded experiment, each with its own run_*.py
├── figures/         thesis figures and the scripts that draw them
└── *.md             methods / results specs (see "Docs" below)
```

The tools talk through files, not imports:
`Simulation` (or real data) → `GUI2` annotate → `Parameter_opt` tune → `SCP` with the tuned params.

## Datasets

All are seeded, so they can be regenerated byte-for-byte. The `.tif` movies are git-ignored
(~2.5 GB); labels, coordinates and `manifest.json` are tracked.

| folder | made by | used by |
|---|---|---|
| `Simulation/dataset/` | `generate_dataset.py` (config `real_calibrated.yaml`) | `real_calibrated_sim_transfer` (the headline T6 run) |
| `Simulation/dataset_valband/` | `generate_dataset.py` (config `real_calibrated_valband.yaml`) | `real_calibrated_sim_transfer` (leak-free rerun) |
| `Simulation/dataset_bt/` | `generate_dataset_bt.py` | `validate_against_real.py --label BT-sim` → `validation/BT-sim/` (baseline) |
| `experiments/*/dataset/` | that experiment's own `run_*.py` | that experiment only |

## Experiments

In the order they were run. Each folder holds its driver, `run_log*.txt` and `optimization_results*.json`.

| folder | question |
|---|---|
| `local_smoke_test/` | Does the train → validate → test wiring work end to end? (5 trials, reduced data; a plumbing check, not a result) |
| `sim_guided_real_selection/` | Tune on the legacy simulator, select on the real movie. Transferred poorly. |
| `bt_simulator_threshold_calibration/` | Tune on the BachelorThesis simulator, calibrate only the threshold on real. |
| `direct_real_spatial_crossval/` | Tune directly on the real movie with a spatial train/val/test split. An oracle upper bound, not a competitor. |
| `sim_vs_real_transfer_comparison/` | Arms A / A2 / B / C: how far does pretraining on the BT simulator carry? |
| `real_calibrated_sim_transfer/` | **Gate T6**: tune on the real-calibrated simulator, report held-out real band (F1 0.7143 vs 0.256 before), plus a random-draw control. |
| `unified_benchmark_rescoring/` | Re-score SCP, Papylio and DeepFRET with one scorer over one region. Has its own README. |

Every `run_*.py` locates the project as `Path(__file__).parent.parent`. Keep experiment
folders exactly one level under `experiments/`.

## Gotchas

- **`legacy_generate_dataset_smtirf.py` writes to `Simulation/dataset/`**, the same place and
  file names as the current `generate_dataset.py`. Running it overwrites the T6 dataset.
- `Parameter_opt/SCP_parametrizer_002.py` writes per-trial `_scp_*.json` next to itself
  (git-ignored). Experiments redirect this by setting `pm.OUTPUT_DIR`.
  `_scp_detected_direct_t22.json` is the exception: `sim_vs_real_transfer_comparison/run_transfer.py`
  reads it, so it is tracked.
- `SCP_parametrizer_002.py` has hardcoded absolute paths near the top (`DATASET_MANIFEST`,
  `TEST_TIF`, ...). Experiments override them; when running the tuner directly, edit them first.
- `Simulation/measure_real_movie.py` and `generate_dataset_bt.py` find the BachelorThesis repo
  three levels up. Moving or flattening this folder breaks them.
